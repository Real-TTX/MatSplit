# Mockup (Verlauf)

Diese Datei beschrieb das fruehere eigene Design-System von MatSplit (`.ms-*`-Klassen, `theme.css`, Verlaeufe,
weiche Schatten, Tab-Leiste unten). Es wurde durch **MatUi** ersetzt, das Design aller Mat-Apps aus dem Repository
MatDesign: flacher Look, ein Akzent (`#bf5610`), Menue links bzw. Drawer auf dem Handy, Kopfleiste mit Brotkrumen und
Aktionen, Dialoge statt Rueckfragen des Browsers.

Der aktuelle Vertrag steht in [ui-controls.md](ui-controls.md), die PWA-Details in [pwa.md](pwa.md).
`mockup-reference.png` ist das Bild, nach dem das fruehere Design gebaut war, und nur noch historisch.
